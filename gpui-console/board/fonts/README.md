# Fonts for the board in a browser

A page starts with no fonts, so the board brings its own (`src/lib.rs`, `web_fonts`); natively it uses the
system's. Both faces are under the SIL Open Font License 1.1, whose text is beside them.

| file | face | from | license |
| --- | --- | --- | --- |
| `IBMPlexSans-Regular.ttf`, `IBMPlexSans-SemiBold.ttf` | IBM Plex Sans | <https://github.com/IBM/plex> | `IBMPlexSans-OFL.txt` |
| `Lilex-Regular.ttf` | Lilex (the monospaced face, for paths and verdicts) | <https://github.com/mishamyrt/Lilex> | `Lilex-OFL.txt` |
