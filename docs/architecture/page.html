Holon System Map

The systems, each shown on its own and then in conversation with the others. A box is coloured by what it is made of, so the line between sandboxed guest code and native processes is visible everywhere.

    Hover or focus a system to light up everything it talks to; open it to see it alone, with each correspondence numbered. The map draws the primary correspondences only. The Correspondences tab lists all of them.
