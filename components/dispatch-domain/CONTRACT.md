# `dispatch:domain` — the contract

A field-service dispatch API. A dispatcher takes a request, the system assigns the
nearest engineer, the engineer moves it through a lifecycle, and the day's manifest
counts what happened.

Three parts write this at the same time, against this file. It is the only thing
they share, so anything not written here is not agreed. If it is wrong or missing
something you need, write `CONTRACT-REQUEST.md` — first line the subject, the rest
why — and the other parts answer between generations. Do not edit this file.

## The stored document

One collection, `requests`. Every part reads and writes this shape and no other.

```json
{
  "title": "Boiler leaking, badly",
  "notes": "caller said [EMAIL] is the best way to reach them",
  "lat": 47.4790,
  "lon": 19.0600,
  "state": "new",
  "engineer": "",
  "distance_m": 0,
  "created": "2026-09-02T09:00:00Z"
}
```

- `notes` is stored **masked**, never raw. The caller's email and phone are in it.
- `engineer` is `""` and `distance_m` is `0` until the request is assigned. They are
  written by `schedule` and by nothing else.
- `distance_m` is an **integer number of metres**, rounded half-up from the
  great-circle distance between the engineer's base and the request's point.
- `created` is RFC3339 UTC, from the store's own `created` on the record — this
  world imports no wall clock.
- Indexed fields, passed to `records::create`: `state` and `engineer`. Anything else
  means listing and filtering.

`GET`ting a request returns this document with `"id"` merged in.

**`find_by` and `query` want the JSON ENCODING of a value, not the value.**
`record-store` indexes the serialised form, so a string field `new` is indexed under
`"new"` — quotes included. A wrong query returns `Ok(vec![])`, which is
indistinguishable from an empty collection, so this fails silently.

## The engineer roster

Fixed, and part of the contract because two parts need the same numbers. There is no
engineer collection and no route that returns this; it is data every part compiles in.

| engineer | lat | lon |
|---|---|---|
| `ada` | 47.4979 | 19.0402 |
| `bela` | 47.5316 | 19.0430 |
| `cili` | 47.4700 | 19.0600 |

## The lifecycle

```
new ──assign──▶ assigned ──depart──▶ enroute ──complete──▶ done
 │                   │
 └────cancel─────────┴────cancel────▶ cancelled
```

`done` and `cancelled` are terminal. The machine is named `dispatch` and an
instance's id is the request's id.

## Routes

### `requests` — POST /api/requests, GET /api/requests, GET /api/requests/{id}

**`POST /api/requests`** takes `{"title", "lat", "lon", "notes"}`.

- `201` with the document and its `id`.
- `400 {"error":"invalid"}` when `title` is missing or blank, or `lat`/`lon` are
  absent or not numbers.
- `400 {"error":"bad_coordinate"}` when `lat` is outside -90..90 or `lon` outside
  -180..180.
- `409 {"error":"duplicate","existing":"<id>"}` when a request with the same `title`
  AND the same `lat` and `lon` already exists in a state that is not `done` and not
  `cancelled`. A finished job does not block a new one — the boiler leaked again.

**`GET /api/requests`** lists them, `{"requests":[…]}`, sorted by `created` then `id`.
Optional `?state=` and `?engineer=` filters, ANDed when both are given.

**`GET /api/requests/{id}`** returns one, or `404 {"error":"not_found"}`.

### `schedule` — POST /api/requests/{id}/assign, POST /api/requests/{id}/transition, GET /api/queue

**`POST /api/requests/{id}/assign`** picks the engineer from the roster whose base is
the **shortest great-circle distance** from the request's point, writes `engineer` and
`distance_m` onto the document, fires `assign`, and answers `200` with the document.

- `404` when the request does not exist.
- `409 {"error":"illegal_transition","state":"<current>"}` when the request is not in
  `new`. The state in the body is the state it is in NOW.

**`POST /api/requests/{id}/transition`** takes `{"event":"depart"|"complete"|"cancel"}`,
fires it, updates the document's `state`, and answers `200` with the document.

- `400 {"error":"invalid"}` when `event` is missing or not one of the three.
- `409 {"error":"illegal_transition","state":"<current>"}` when the move is not legal
  from the current state.

**`GET /api/queue`** returns `{"queue":[…]}` — every request that is not `done` and
not `cancelled`, sorted by `distance_m` ascending, then by `id`. Unassigned requests
have `distance_m` of `0` and therefore sort first.

### `manifest` — GET /api/manifest, GET /api/manifest.csv

**`GET /api/manifest`** answers:

```json
{
  "total": 4,
  "by_state": {"new": 1, "enroute": 2, "done": 1},
  "by_engineer": {"ada": 2, "cili": 1},
  "total_distance_m": 12345
}
```

- `by_state` and `by_engineer` contain **only keys that occur**. No zero-filling. An
  unassigned request contributes to no engineer at all — `""` is not a key.
- `total_distance_m` is the sum of every `distance_m`, as an integer.
- A day with nothing in it is a manifest of zero, not a `404`.

**`GET /api/manifest.csv`** answers the same set as `text/csv`, one row per request,
sorted by `id`, with a header row:

```
id,title,state,engineer,distance_m
```

The content type must be `text/csv`. A title containing a comma must come back
quoted, or the row stops having five columns.

**Both routes accept an optional radius filter**: `?near_lat=&near_lon=&within_m=`.
When all three are present, only requests whose point is within `within_m` metres of
the centre are counted or listed. Any of the three missing means no filter. A
malformed number in any of them is `400 {"error":"invalid"}`.

## What you must not write yourself

Your part's world already contains the hard pieces, as components, bound at compose
time. Look at `wit/dispatch.wit`. What is imported there is implemented, tested and
composed for you — you call it, you do not write it. Each gate reads the compiled
component's imports, so writing your own passes the behaviour and fails the gate.

- **Masking** is `pii:redact/redactor`. `redact` with empty `kinds` means every kind.
- **The lifecycle** is `fsm:workflow/engine`. `define` it once, then one instance per
  request. `IllegalTransition(String)` carries the current state, which is exactly
  what the 409 body needs.
- **Distance and radius** are `geo:resolve/coords`: `distance-meters` for the nearest
  engineer, `bounding-box` plus `contains` for `within_m`. Two parts import this, and
  a hand-rolled haversine in one of them disagrees with the other — which is a
  failure your own gate cannot see and the composition gate can.
- **CSV** is `csv:codec/codec`'s `format`. `Dialect.delimiter` is a `String`, not a
  char: `",".to_string()`. A file is a `Vec<Row>` and the header is just the first
  row.
